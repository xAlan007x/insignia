# Insignias de GitHub

Guía interactiva en español para entender los logros visibles en un perfil de GitHub y revisar datos públicos de una cuenta.

## Qué hace

- Resume los logros de perfil que se pueden intentar sin pagar.
- Distingue logros activos, históricos y los que dependen de otras personas.
- Consulta la API pública de GitHub para mostrar repositorios públicos, estrellas y PR fusionados que aparecen en la búsqueda pública.
- Guarda el progreso manualmente en este navegador. GitHub no ofrece un endpoint público de API para leer todos los logros de una cuenta, así que la app no afirma que un contador equivalga a un logro concedido.
- No pide inicio de sesión, permisos ni tokens.

## Uso

Abre `index.html` en un navegador y escribe un nombre de usuario de GitHub. La consulta usa endpoints públicos y está sujeta al límite de solicitudes anónimas de GitHub.

## Alcance y precisión

Los nombres y la disponibilidad cambian. GitHub mantiene los logros en vista previa pública y no publica un catálogo completo con todas las reglas y umbrales. La app separa los criterios descritos por GitHub de los umbrales reportados por la comunidad.

Logros activos que aparecen en la guía:

- Quickdraw
- YOLO
- Pull Shark
- Pair Extraordinaire
- Galaxy Brain
- Starstruck
- Public Sponsor (requiere patrocinio con coste, por eso queda fuera del filtro gratuito)

Arctic Code Vault Contributor y Mars 2020 Contributor son históricos y ya no se pueden obtener. Heart On Your Sleeve y Open Sourcerer no tienen lanzamiento público confirmado en las fuentes consultadas.
