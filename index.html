Revisión de GitHub
01

Lo que la API puede comprobar

Repositorios públicos, estrellas y algunos datos visibles. La API pública no informa qué logros tiene una persona.

02

Lo que depende de la comunidad

Un PR aceptado, una respuesta elegida o una coautoría real requieren trabajo útil y la participación de otras personas.

03

Umbrales con contexto

GitHub mantiene Achievements en vista previa y no publica una tabla completa de criterios. Los números se etiquetan como referencias comunitarias.
